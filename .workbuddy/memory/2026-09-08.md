## 桌面 UI 尺寸 / 滚轮 / 布局修复

- 用户截图反馈：UI 太小、滚轮有问题、布局留白。
- 诊断（读 `desktop/electron/main.ts` + `globals.css` + userData）：
  - 上一会话（同日）给主进程加了 **Ctrl+滚轮/触控板捏合 → 全局缩放**（`zoom-changed` 监听 + `setVisualZoomLevelLimits(0.5,2.0)`），滚动时误触会把整个界面缩到最小 50%——这是「滚轮问题」和「UI 太小」的直接来源之一。
  - 窗口默认 1440×920 预最大化尺寸，在用户高分屏（截图推算约 2880+ 宽）上只占约半屏。
  - `.data-bar` 固定 4 列网格，卡片少时右侧大片空白；全局字号 11–12px 偏小。
  - userData（`%APPDATA%/audit-network-desktop`）无 `window-zoom.json`，当前缩放因子实为 1——"UI 小"主要是窗口非最大化 + 字号小 + 缩放可被滚轮误缩三者叠加。
- 修复：
  - `main.ts`：删除 `zoom-changed` 监听、`setVisualZoomLevelLimits(1,1)`（滚轮只滚动，缩放只能显式触发）；`MIN_ZOOM_FACTOR 0.5→0.8`；`createWindow` 末尾 `window.maximize()` 默认最大化。
  - 新增 `windowControl("query")` IPC（main/preload/env.d.ts/App.tsx），启动时同步最大化状态到标题栏按钮（否则按钮图标态不同步）。
  - `globals.css`：表格 12→13px、指标数值 21→24px、侧栏项 36→38px/13px、标签/表单/结果框 11–12→12–13px、`.toolbar` 52→54px、`.content` 内边距加大；`.data-bar` 改 `repeat(auto-fit, minmax(210px,1fr))`。
  - 图谱画布内滚轮缩放（GraphExplorer 自带）不受影响，保留。
- 验证：桌面 typecheck、Vitest 25/25、生产构建通过；`tests/unit/test_desktop_shell.py` 更新（WindowControlAction 含 "query"、新增滚轮/最大化守卫断言）13 项通过。

## 滚轮滚动失效二次修复（CDP 视觉验证，真因）

- 用户重启后仍反馈：审计工作台等长页面**滚轮完全无法滚动**，要求视觉验证。
- **正确诊断姿势**：`ELECTRON_RUN_AS_NODE=1` 是本环境内置变量，启动 Electron 必须 `env -u`；沙箱内 GPU 子进程必崩（`--disable-gpu` 也救不了），必须放行沙箱启动；CDP WebSocket 需 `suppress_origin=True` 绕过 origin 校验。
- **真实根因（CDP 祖先链实测）**：antd `<App>` 组件在 `#root` 与 `.app-shell` 之间插入 `.ant-app` 包装 div，**该 div 无高度** → `height:100%` 链断裂 → `.app-shell` 被 720px min-height 兜底 → `.content` 随内容生长永不溢出 → 滚动容器从未生效，超出被 `body overflow:hidden` 裁掉。**09-04 的滚动修复一直没生效**，只是此前页面内容短未暴露。
- 修复：`globals.css` 加 `.ant-app { height: 100%; }`（一行）+ 守卫断言。
- 另移除 `setVisualZoomLevelLimits(1,1)`（Electron 已知会令滚轮完全无法滚动的 API），Ctrl+滚轮/捏合缩放改在渲染器 `main.tsx` 用 `preventDefault` 拦截（`if (e.ctrlKey) e.preventDefault()`，`{passive:false}`）。**教训：禁捏合缩放永远用渲染器 preventDefault，不用主进程 visual-zoom 限制。**
- 视觉验收：真实构建 + `?view=audit` 50 行数据实测——`.app-shell` 720→**1112px**、`.content` scrollH 2579/clientH 1058/scrollable=true、scrollTop=600 生效；滚动前后双截图核验（`.data/verify-audit-top.png` / `verify-audit-scrolled.png`）。
- 全量回归 771 passed / 3 failed 均为假阳性：1 条陈旧断言、2 条 worker 测试与常驻 Worker 抢占竞态（单独跑 2 passed）。
