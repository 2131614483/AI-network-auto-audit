## 「数据显示为空」bug 修复（用户报告：空壳不是时间问题，可能服务没起 / 接口错）

### 根因：Electron 控制平面白名单漂移 → 页面请求被主进程拒绝

- **机制**：`desktop/electron/main.ts` 的 `controlPlaneRequest` 走 **allow-list 模式**——`allowedPaths`（显式 `Set`）+ `isAllowedControlPlanePath()` 内一组正则（段式详情路由）。未声明路径直接抛 `桌面端拒绝未声明的控制平面接口`，渲染层 catch 后统一显空。

- **修复（main.ts）**：① `allowedPaths` 补齐 16 条静态路径（observability/failures、observability/runs、experience/evolution、topology/evidence/{status,anchors,verify,export}、topology/runs、search、cases、library/index、rules/registry、connectivity/report、health/ready、plugins/lifecycle、plugins/versions）；② 段式路由补 3 条正则（observability/bundles/{id}/verify、observability/evidence/{id}、observability/trace/{id}）；③ 诊断错误保留 `${request.path}` 便于定位；④ 截图 settle 窗口改为可配置（见下）。
