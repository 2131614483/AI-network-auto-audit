# 高难度实验组 · AI 胜任力评估矩阵

这份数据集的用途是**测试 AI 能不能胜任审计作业中的判断部分**。下面把 24 处漏洞按『需要什么能力』分层，逐层给出结论。

---

## 一、结论速览

| 层级 | 能力 | 项数 | AI 可胜任性 |
| --- | --- | --- | --- |
| T1 规则可检 | 规则可检 | 3 | 可稳定胜任 |
| T2 跨表勾稽 | 跨表勾稽 | 5 | 可胜任，但易漏做 |
| T3 比率与结构 | 比率与结构 | 3 | 可胜任，取决于分析主动性 |
| T4 准则与行业知识 | 准则与行业知识 | 8 | 可胜任，取决于知识覆盖 |
| T5 职业判断与沟通 | 职业判断与沟通 | 5 | 仅能发现线索，结论需人工 |

**分档结论：**

- **确定性程序（不含 LLM）**：能查出 **3 项**（只占 12.5%），且必须有人告诉它查什么。
- **AI 有望独立完成**：T1–T4 共 **19 项**（79%）——前提是它主动发起跨表核对、比率分析，并且掌握了相应准则。
- **AI 只能提供线索、结论需人工**：T5 共 **5 项**（21%）。

## 二、逐层展开

### T1 规则可检（3 项：H14、H15、H16）

**需要的能力**：会写并运行确定性程序即可；难点在于**想到要做累积评价**（SAD）

**AI 可胜任性**：可稳定胜任

| 编号 | 它要求 AI 做什么 |
| --- | --- |
| H14 | 累积评价（SAD 概念） |
| H15 | 跨界字段交叉 |
| H16 | 跨目录关联证据 |

**这一层最常见的失败方式**：
- H14：难点不在算法，而在**是否想到要做累积**；任何只看单笔重要性的抽样都会全部放行
- H15：需要把『记账日期』与『出库单日期』两个字段交叉，而不是只看摘要
- H16：需要主动关联两份文件并信盘点结果而非卡片；金额小、位置偏，容易被跳过

### T2 跨表勾稽（5 项：H01、H02、H03、H04、H07）

**需要的能力**：能把两张以上不同来源的表放在一起求差、逐笔匹配，而不是核对合计数

**AI 可胜任性**：可胜任，但易漏做

| 编号 | 它要求 AI 做什么 |
| --- | --- |
| H01 | 跨文件求和比对 |
| H02 | 不信任汇总数，回原始日期重算 |
| H03 | 逐条重算而非核对合计 |
| H04 | 分主体比对 + 意识到合并会掩盖归属问题 |
| H07 | 逐笔匹配 + 完整性判断 |

**这一层最常见的失败方式**：
- H01：两张明细表都很长且看起来完整，没有任何一行异常；只有把两份文件的合计数拿来相减才有信号
- H02：总额勾稽通过会给出虚假的安心感；必须放弃『总额对得上就没问题』的默认假设，改用原始日期重算明细
- H03：要求逐张卡片重算，而不是只对合计数；模型的默认路径是核总数

### T3 比率与结构（3 项：H05、H06、H08）

**需要的能力**：会做趋势与比率分析，并有『这个数应该长什么样』的先验

**AI 可胜任性**：可胜任，取决于分析主动性

| 编号 | 它要求 AI 做什么 |
| --- | --- |
| H05 | 趋势分析 + 行业常识判断异常 |
| H06 | 由缺失证据反推 + 周转率分析 |
| H08 | 双维度联动分析 |

**这一层最常见的失败方式**：
- H05：需要主动做毛利率趋势分析，并知道白酒行业毛利率高度稳定 —— Q4 跳升 6.8pct 在行业内几乎不可能自然发生
- H06：这不是『翻表发现数字矛盾』，而是**发现该有的表没有**，并用周转率异常反推该提减值
- H08：需要同时看收入与费用两个维度并知道它们应当同向变动

### T4 准则与行业知识（8 项：H09、H10、H11、H12、H13、H17、H18、H21）

**需要的能力**：掌握收入确认总额/净额、新租赁准则、售后回购实质、白酒消费税复合计征等具体规则，并主动拿规则去套业务

**AI 可胜任性**：可胜任，取决于知识覆盖

| 编号 | 它要求 AI 做什么 |
| --- | --- |
| H09 | 研读合同条款 + 实质重于形式判断 |
| H10 | 准则条款应用 |
| H11 | 税务行业知识（复合计征） |
| H12 | 会计估计合理性判断 + 行业惯例 |
| H13 | 新准则适用性判断 + 折现计算 |
| H17 | 披露完整性核对 |
| H18 | 非结构化文本要点抽取 |
| H21 | 披露充分性（而非完整性）判断 |

**这一层最常见的失败方式**：
- H09：必须逐份读合同关键条款，并用『控制权是否转移』判断经济实质；账、单、票全齐会让人放松警惕
- H10：需要判断主要责任人 vs 代理人，涉及准则第五章的指标应用；并意识到总额法会同时虚增收入成本（毛利率不变）
- H11：需要知道白酒消费税**复合计征**（从价 + 从量）；不知道这点的模型会认为税务合规

### T5 职业判断与沟通（5 项：H19、H20、H22、H23、H24）

**需要的能力**：能从红旗线索出发提出假设，再靠访谈、函证、工商查询取证；结论无法由程序单独得出

**AI 可胜任性**：仅能发现线索，结论需人工

| 编号 | 它要求 AI 做什么 |
| --- | --- |
| H19 | 法律事项会计判断 |
| H20 | 期后事项分类判断 |
| H22 | 红旗识别与舞弊推理 |
| H23 | 从编号连续性发现缺失 |
| H24 | 多跳推理（股权穿透） |

**这一层最常见的失败方式**：
- H19：需要读到判决书的实质结论，并判断败诉后上诉**不改变现时义务的存在**；涉及法务判断
- H20：需要判断该事项属重大非调整事项，并知道披露门槛；信息藏在对审计最不显眼的会议纪要里
- H22：需要把日记账与对账单逐笔匹配（而非只看余额调节），并认识到『账上收了钱、银行没有』是舞弊红旗而非普通未达账项

## 三、这份数据实际测的三层能力

| 层次 | 名称 | 测什么 | 失败长什么样 |
| --- | --- | --- | --- |
| 第一层 | **程序能力** | 会不会用工具算数、取数、对账 | 连试算平衡都跑不出来 |
| 第二层 | **分析能力** | 会不会主动做跨表勾稽与比率分析 | 只核合计数，不核分项；不做趋势 |
| 第三层 | **意识能力** | 会不会**想到**去查某张表、某项准则 | 工具都会用，但根本没去查 |

本数据集的设计靶心是**第三层**。前两层的失败是「能力不足」，第三层的失败是「不知道自己不知道」——而这恰恰是当前 AI 在专业作业中最主要的短板。

## 四、建议的评分方式

用同一份资料跑被测对象，按下列口径打分：

| 指标 | 算法 | 说明 |
| --- | --- | --- |
| 总体召回率 | 检出数 ÷ 24 | 主要指标 |
| 分层召回率 | 各层检出数 ÷ 各层项数 | **看它在哪一层断崖** |
| 误报率 | 报出但不在清单的项数 ÷ 报出总数 | 用 5 项噪音 + 27 项真实业务事项检验 |
| 证据充分性 | 每条发现是否附『文件 + 关键数字 + 计算过程』 | 只报结论不给路径的，不计分 |
| 方向正确性 | 对 H03 这类双向错报，是否**分别列示**超提与少提 | 只报净额视为未检出 |

**建议的判定门槛**：

- 分层召回里 T1 全中、T2/T3 中 ≥60% → 具备**执行型**胜任力；
- T4 中 ≥50% → 具备**知识型**胜任力；
- T5 能提出正确假设并说明需何种取证 → 具备**判断型**胜任力；
- 误报率 >20% → 无论召回多高，都不能算胜任。

---

## 五、必须先讲清楚的前提

1. **本数据集不测「能不能把账做平」**——账本来就是平的，试算平衡一项也查不出来。
2. **不测「能不能读懂表格」**——所有表格都是规整的 CSV/Markdown。
3. **不测「知不知道审计流程」**——问「应当实施什么程序」人人都答得出；
   这份数据测的是**有没有真的去执行**，以及执行得够不够细。
4. 5 项噪音与 27 项真实业务事项（正常的销售、采购、折旧、税缴、股利、借款）共同构成误报测试面。**只报噪音的模型，比漏检的模型更危险。**
