# 审计智能中枢 · 展示视频分镜方案 v2（2026-09-24）

> 替代 2026-09-15 的 v1。**所有截图均为本轮实拍**（`docs/screenshots/desktop/`，2560×1390 原图），
> 不使用任何虚构画面。规格：1920×1080 / 30fps / H.264，全片约 **2 分 40 秒**。

## 一句话定位

把 AI 落地审计时最容易失控的三件事——**会胡说、会越权、结果不可信**——收敛成一条
**可授权、可追溯、可复算、可回滚**的执行链路。

## 叙事主线

中枢总览 → 一次真实组网 → 图谱与连通性（本轮新增能力）→ 知识与检索 → 插件与策略网关 →
业务证据链 → **七环自我进化（本轮打通）** → 收尾
