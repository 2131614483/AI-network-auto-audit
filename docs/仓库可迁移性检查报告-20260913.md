## 四、"陌生人下载"的真实流程 vs README 描述

README 说：**双击 `启动审计智能中枢.bat`**。实际需要的是：

```
1. 装 Python 3.11+/3.12                        ← README 未提
2. 建 venv 并 pip install -e '.[dev]'          ← README 未提
3. 装 Node 20                                  ← README 未提
4. npm install --prefix desktop（会拉 Electron）← README 未提，受限网络会失败
5. cp .env.example .env 并按机器改值            ← README 未提
6. 装 PostgreSQL 16 + pgvector（Windows 需单装）← README 未提
7. 超管跑 scripts/init-native-postgres.sql + 设密码 ← README 未提
8. 建测试库 audit_network_test + 装四个扩展      ← 仅测试需要，README 未提
9. .\启动审计智能中枢.bat --migrate             ← README 提到 --migrate，但没说新机器必须加
10. 双击 .bat                                   ← README 只写了这一步
```
