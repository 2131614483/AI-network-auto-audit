## 4. 修复方案

### 阶段一 · 回填（通电环 2/3/4）— 不需写新功能，只写一个驱动脚本

> **执行状态：✅ 已完成（2026-09-23）**，脚本 `scripts/backfill-experience.py`。实测结果见 §4.5。

**为什么必须逐 run 调 `project_run`，不能只调 `rebuild`**：
`rebuild()`（`projector.py:376`）先 `DELETE FROM experience.edge_stats/node_stats`，再从**已有观测**重建——观测为 0 时它产出 0。观测只能由 `project_run(tenant_id, run_id, trace_id)` 从 `control.node_attempts` 现算。

**新增 `scripts/backfill-experience.py`**（只读 run 台账，写经验四表）：

1. 取租户 `local-dev` 的全部 `run_id` 及其 `trace_id`（`control.node_attempts` 按租户分组）。
2. 对每个 run 调 `ExperienceProjector(url).project_run(tenant_id=…, run_id=…, trace_id=…)`，收集返回的 summary 字典。
3. 汇总打印：`handovers / edge_observations_inserted / node_observations_inserted / edges_recomputed / nodes_recomputed / suggestions_upserted`，并打印失败 run（若有）。
4. 支持 `--dry-run`（只算不写）与 `--tenant` 参数；默认对 dev 库、显式 `--yes` 才写。

**安全性**：观测表是 append-only + `ON CONFLICT (tenant_id,run_id,source_instance,target_instance,contract_id)` 幂等；候选表对 `accepted/dismissed` 冻结不复活（`accumulates_evidence`）。脚本可重复执行，不会翻倍。

**退出条件（实测数字，不是主观判断）**：

| 指标 | 期望（试算值） |
|---|---|
| `experience.node_observations` | ≈ 1726 |
| `experience.edge_observations` | ≈ 1102 |
| `experience.node_stats` / `edge_stats` | > 0 |
| `experience.relation_suggestions` | 1 – 13 |
| 环 2/3/4 界面状态 | 半通 → **已通**（绿灯） |

## 8. 附加发现：Run 画布异常会打崩整个桌面端（建议一并修）

阶段二操作过程中触发并定位，与本方案主线无关，但**影响面比环 7 更大**。

### 8.1 现象

桌面端整片空白：`#root` 子节点数 **0**、`document.body.innerText.length` **0**、侧栏 42 个菜单项全部消失，而 `<html data-connection>` 仍是 `online`（该标记在崩溃前写入）。用户看到的就是一个全黑窗口，没有任何提示。

### 8.2 根因

`desktop/src/components/RunCanvas.tsx` 的平移处理把**可变 ref 的读取放进了 state updater**：

```tsx
const movePan = (event: React.MouseEvent) => {
  if (!dragRef.current) return;
  setTransform((c) => ({ ...c,
    tx: dragRef.current!.tx + (event.clientX - dragRef.current!.x),   // ← 在这里读 ref
    ty: dragRef.current!.ty + (event.clientY - dragRef.current!.y) }));
};
const endPan = () => { dragRef.current = null; };                     // ← 先被置空
```

`setTransform` 的 updater 是**稍后**由 React 执行的。若 `mouseup`（`endPan`）先到，updater 执行时 `dragRef.current` 已是 `null`，`!` 非空断言只骗过编译器、骗不过运行时 → `TypeError: Cannot read properties of null (reading 'tx')`。堆栈形态吻合：`TypeError ... RunCanvas.tsx ... at basicStateReducer (react-dom) at updateReducer` —— 异常正是在 reducer 调用 updater 时抛出。

### 8.3 为什么后果这么严重

`apps/desktop` 的 React 树**没有错误边界**，未捕获的渲染/更新异常会让 React 卸载整棵树 —— 于是「画布平移竞态」升级成「整个控制台白屏」。这也解释了此前两次被误判为"重载把应用打坏"的全黑窗口：根因很可能就是这个异常，而非重载本身。

### 8.4 修法（两处，都很小）

> **执行状态：✅ 已完成并实测验证（2026-09-23）**，结果见 §8.6。

1. **消除竞态**：在调用 `setTransform` 前把 ref 快照成局部变量，updater 只闭包该局部量，不再触碰 ref。

   ```tsx
   const movePan = (event: React.MouseEvent) => {
     const drag = dragRef.current;
     if (!drag) return;
     setTransform((c) => ({ ...c,
       tx: drag.tx + (event.clientX - drag.x),
       ty: drag.ty + (event.clientY - drag.y) }));
   };
   ```

   同文件紧邻的 `moveNodeDrag` **已经是正确写法**（`const drag = nodeDragRef.current; if (!drag) return;` 之后再闭包 `drag`），所以这条修法不是引入新风格，而是让 `movePan` 与隔壁保持一致。已核对其余 ref 用法无同类问题。

2. **兜底**：给 `renderView()` 的页面区加一个 ErrorBoundary，崩溃时显示可读错误 + 「重新加载」而不是白屏。这一条独立于本 bug —— 任何页面异常都不该让整个控制台消失。

### 8.5 建议顺序

**先做 8.4 的第 1 条**（3 行改动、零行为变化，直接消灭竞态），第 2 条可与阶段三并行。

## 9. 附加发现（二）：控制台里的两条 antd 告警，一条是噪音、一条是真缺陷

来源：用户在「统一日志」里看到的渲染器告警。两条都不是本方案主线，但都在日志里以**错误**级别刷屏。

### 9.1 `[antd: Table] 'index' parameter of 'rowKey' function is deprecated` —— 噪音 + 潜在行身份错位

**全仓只有一处**：`desktop/src/App.tsx` 审批中心表的 `rowKey={(row, index) => ...}`。

**为什么不只是噪音**：index 做 key 在列表重排 / 分页时会让行身份漂移，而该表带 `expandable`，展开态可能挂到**错误的行**上；antd 也明确说 index「不做保证」。

**修法**：`rowKey={(row) => row.id ?? `${row.capability}-${row.trace_id ?? row.created_at}`}` —— 优先用审批记录的主键 `id`（接口确实返回），缺失时退回到不含 index 的稳定组合。

**验证**：整体重载（新会话，antd 告警按会话去重，旧会话的去重表会掩盖问题）后进入审批中心 —— 表 **200 行 + 200 个展开图标**正常渲染，告警累计数 **4 → 4 不增**。

### 9.2 `[antd: compatible] antd v5 support React is 16 ~ 18` —— **真缺陷：静态 `message.*` 静默失效**

这一条不是噪音。React 19 下 antd v5 的**静态方法**（`message.*` / `notification.*` / `Modal.*`）不报错、只是**什么都不弹**。

**实测复现**（修复前）：在「文档资产库」点击路径单元格（该 `<span>` 的 `onClick` 就是 `message.success("路径已复制")`）——
点击目标确认为 `docs/acceptance-2026-09-05.md`，而 `document.querySelectorAll(".ant-message")` **= 0**，页面上也没有任何"复制"字样。
**用户点了复制，界面一声不吭。**

**受影响面**：全仓 **7 处 / 6 个文件**，其中 **3 处是错误提示**（静默失败最危险）：

| 文件 | 调用 |
