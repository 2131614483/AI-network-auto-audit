# 应收账款保理合同摘要

**合同编号**：BL-2025-018　**签订日期**：2025-09-20

| 项目 | 内容 |
| --- | --- |
| 保理银行 | 中国建设银行贵阳分行 |
| 保理方式 | **有追索权保理（明保理）** |
| 保理标的 | 对 3 家经销商的应收账款，账面余额 **150,000,000.00** 元 |
| 融资金额 | 135,000,000.00 元 |
| 保理费率 | 年化 4.8% |
| 追索权安排 | **★ 银行保留对本公司的完全追索权**，应收账款不能收回时本公司须回购 |

## 会计处理与问题

财务部将该笔应收账款 **终止确认**，收到融资款记入「银行存款」，差额计入「财务费用」。
**未在附注中披露质押、追索权安排及受限情况**（E14）。

> 按《企业会计准则第 23 号——金融资产转移》，附追索权的保理不满足终止确认条件，
> 应确认为 **短期借款**，同时继续确认应收账款。
