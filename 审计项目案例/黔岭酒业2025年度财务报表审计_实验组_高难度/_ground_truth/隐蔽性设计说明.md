# 高难度实验组 · 隐蔽性设计说明

这份数据与前两版最大的差别：**资料里没有任何标记**。
`_tools/selfcheck.py` 会扫描全部 51 个资料文件，确认不含 ★、『应提/核对结果/异常/错误』等提示性用语。

下面说明每一处漏洞**具体是怎么藏的**。

| 编号 | 藏在哪儿 | 为什么单看一张表看不出来 |
| --- | --- | --- |
| H01 | 总账三处各自平衡；差额只在『采购发票登记簿汇总金额』与『存货入库明细汇总金额』两个不同来源的合计数相减时出现 | 两张明细表都很长且看起来完整，没有任何一行异常；只有把两份文件的合计数拿来相减才有信号 |
| H02 | 账龄表合计数与总账应收账款**完全一致**，表面无任何差；只有拿销售台账的『原始赊销日期』逐笔重算账龄，才发现年份归属被改 | 总额勾稽通过会给出虚假的安心感；必须放弃『总额对得上就没问题』的默认假设，改用原始日期重算明细 |
| H03 | 两个方向的错误**互相抵消**，折旧总额只差 451,250 元，远低于重要性水平；只看『本期折旧合计 vs 软件折旧汇总』会直接放行 | 要求逐张卡片重算，而不是只对合计数；模型的默认路径是核总数 |
| H04 | 合并层面完全抵消，合并报表看不出任何问题；只有**分主体**把申报表与账面对，才发现归属错位 | 大部分程序默认在合并层面做，跨主体归属类问题天然隐形 |
| H05 | 凭证摘要写『按预算成本结转』，是**正常业务语言**；单看每个月都不异常，只有把四个季度的毛利率画成趋势线才看出突变 | 需要主动做毛利率趋势分析，并知道白酒行业毛利率高度稳定 —— Q4 跳升 6.8pct 在行业内几乎不可能自然发生 |
| H06 | 资料包里**没有**『存货跌价测试表』（管理层没做）；信号只存在于收发存明细的期初期末余额与销售数量之间 | 这不是『翻表发现数字矛盾』，而是**发现该有的表没有**，并用周转率异常反推该提减值 |
| H07 | 『货到票未到』在年末是常态，入库单上『对应发票』栏为空不会引起注意；且金额低于重要性水平，需与 H01 合并评价 | 需要把《存货入库明细》逐笔与《采购发票登记簿》匹配，找出**没有对应发票也未暂估**的入库；单看任一张表都看不出问题 |
| H08 | 凭证与明细都没有异常行；异常是**两个比率同时朝不合逻辑的方向走** （收入涨、费用率反降） | 需要同时看收入与费用两个维度并知道它们应当同向变动 |
| H09 | 账务处理与普通销售**完全一致**，出库、开票、收款单据齐全；唯一线索写在《重大合同台账》的『关键条款』里 —— 一行字的回购约定 | 必须逐份读合同关键条款，并用『控制权是否转移』判断经济实质；账、单、票全齐会让人放松警惕 |
| H10 | 毛利率虽低但为正，看起来是一笔『薄利的大生意』，完全合理；线索在合同标题『代理销售协议』与结算条款（按佣金结算） | 需要判断主要责任人 vs 代理人，涉及准则第五章的指标应用；并意识到总额法会同时虚增收入成本（毛利率不变） |
| H11 | 《纳税申报与缴纳汇总》的从价税额与收入×20%**完全吻合**，会让人认为税务处理正确；从量税额一栏数字存在但对应数量却在两个关联文件中 | 需要知道白酒消费税**复合计征**（从价 + 从量）；不知道这点的模型会认为税务合规 |
| H12 | 会计政策附注里**确实披露了**『房屋建筑物 20–40 年、窖池 20 年』，披露是完整的；问题是政策本身不合理 | 不是披露缺失，而是**会计估计不合理**。需要横向比对同类资产在附注里的年限区间，发现窖池与普通房屋用了同一区间下限 |
| H13 | 租金按『管理费用–租赁费』正常列支，凭证摘要就写『支付仓库租金』，完全符合旧准则；没有任何『错误』的样子 | 需要主动意识到新租赁准则（CAS 21 修订）要求承租人统一确认使用权资产，并知道要拿租赁合同算现值 |
| H14 | 分散在 12 张凭证，摘要各不相同（『物料采购』『会务费』『办公用品』…），单笔都在任何人的容忍范围内 | 难点不在算法，而在**是否想到要做累积**；任何只看单笔重要性的抽样都会全部放行 |
| H15 | 3 笔分散、金额小；与 H14 混在同一批凭证里 | 需要把『记账日期』与『出库单日期』两个字段交叉，而不是只看摘要 |
| H16 | 盘点表与卡片表**都在**，但盘点表放在『其他资料』而不是固定资产资料里；差额只有 420,000 | 需要主动关联两份文件并信盘点结果而非卡片；金额小、位置偏，容易被跳过 |
| H17 | 借款合同与质押清单都完整归档在『银行资料』里，账务处理也正确；**唯一的问题是没有写进附注** | 账没错、单没错，错在『没说的话』；需要对照披露清单逐项核对，并有『受限资产必须披露』的先验 |
| H18 | 担保决议写在董事会决议**第 4 条**、夹在两页中间，措辞平淡，不带任何数字标题 | 需要通读全部决议文本并抽取担保事项，而非检索关键词；表述用的是『提供增信支持』 |
| H19 | 诉讼材料在『其他资料』里以『法律事项说明』为名，正文把败诉写成『一审结果将于上诉后确定』 | 需要读到判决书的实质结论，并判断败诉后上诉**不改变现时义务的存在**；涉及法务判断 |
| H20 | 并购信息出现在『总经理办公会纪要』而非董事会决议，且表述为『项目交割完成』 | 需要判断该事项属重大非调整事项，并知道披露门槛；信息藏在对审计最不显眼的会议纪要里 |
| H21 | 附注**已经列了**前五名客户的金额，看起来披露是完整的；缺的是『风险提示』这个判断性表述 | 这是『披露了数据但没披露判断』的类型；模型容易把有数字当成已披露 |
| H22 | 账面收款凭证齐全、摘要正常；差异只存在于**银行对账单**里 —— 对账单上没有这三笔入账，而账面日记账有 | 需要把日记账与对账单逐笔匹配（而非只看余额调节），并认识到『账上收了钱、银行没有』是舞弊红旗而非普通未达账项 |
| H23 | 没有任何金额异常；异常在于**单据编号的连续性** —— 这需要主动去查编号区间，而非查金额 | 是『证据链完整性』问题，不是金额问题；程序里没有任何一条会去统计单据编号连续性 |
| H24 | 工商信息给的是单层股权，董事配偶不在股东名单上；必须**穿透两层**（董事配偶 → 中间公司 → 供应链公司）才现形 | 需要主动做股权穿透并关联到关键管理人员近亲属；且中间公司的名称与主业完全无关（『投资管理』），不提供任何暗示 |

## 六种隐蔽手法

1. **跨表错配**（H01、H02、H07）：每张表的合计数都对得上总账，差异只在两张不同来源的表的**分项**之间。
2. **双向抵消**（H03）：同一项目上既有超提又有少提，净影响 451,250 元，低于重要性水平 1,500,000 元 —— 只核总额一定放行。
3. **金额稀释**（H14、H15、H16）：单笔都低于 SAD 限额 75,000 元，分散在不同月份、不同摘要里。
4. **形式合规掩盖实质**（H09、H10、H13）：账、单、票齐全，会计处理在旧准则下毫无问题；要靠**读合同条款**或**套新准则**才能发现。
5. **披露遗漏**（H17、H18、H19、H20、H21）：账务处理全对，问题在『没说的话』。H21 更细：附注**已经列了**前五名客户金额，缺的是判断性表述。
6. **线索藏在非结构化文本里**（H18、H19、H20、H24）：担保写在决议第四条、并购写在总经理办公会纪要、败诉写在「上诉后确定」的措辞里、关联方要穿透两层股权。

## 三处「看起来会报、其实不该报」的设计

| 编号 | 像什么 | 为什么不该报 |
| --- | --- | --- |
| N01 | 大额正常关联交易：向全资子公司销售 800,000,000，定价政策、审批、披露均完整 | 金额巨大且是关联交易，但已在附注完整披露，属正常内部交易 |
| N02 | 会计估计变更：坏账计提比例由 3% 调整为 5%，本期影响 4,200,000，已披露变更性质与影响 | 会影响损益且金额不小，但属合规估计变更并已披露，无需调整 |
| N03 | 收入季节性波动：Q4 收入占全年 38%，系春节前备货所致，与行业销售周期一致 | Q4 收入占比高容易被当成跨期，但出库与签收日期完整、与行业春节前备货周期一致，属正常经营节奏 |
| N04 | 募集资金专户大额支出 480,000,000，用途与披露的募投项目一致 | 大额、集中的资金流出，但用途合规、有决议、有披露 |
| N05 | 存货跌价准备转回：因春酿售价回升转回 2,000,000，有售价回升的第三方证据 | 跌价准备转回容易被质疑为调节利润，但本期确实符合转回条件 |
