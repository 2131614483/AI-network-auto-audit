## 二、数据是怎么造出来的（三点设计）

### 1. 凭证驱动 —— 账不平这件事"造"不出来

全部 89 张凭证都是**复式记账**，逐张借贷相等，因此：

- 三个主体的**试算平衡表天然平衡**（借方合计 − 贷方合计 = 0）；
- 合并资产总计 = 负债合计 + 所有者权益合计是**推理结果**，不是配平结果。

> 换句话说：这批数据里**不存在"账不平"这种低级错报**。所有错报都藏在
> 单据、账龄、卡片、文件里（见第四节）。这符合真实项目的形态 ——
> 客户交给你的账，永远是平的。

### 2. 维度标签即附注 —— 附注不是第二套数据源

每一条分录行都携带辅助核算维度：`客户 / 供应商 / 关联方 / 产品 / 渠道 / 地区 /
税种 / 资产类别 / 使用部门 / 账龄 / 现金流项目`。本资料包里的：

- 销售明细（分产品 / 渠道 / 地区 / 客户）
- 应收账款账龄明细
- 存货收发存明细
- 固定资产及折旧明细
- 期间费用明细（按性质）
- 应交税费明细（按税种）
- 职工薪酬明细

**全部由同一批分录按维度聚合得出**，因此它们与试算平衡表**逐项勾稽**，
不会出现"附注和主表对不上"。

### 3. 固定资产折旧可由卡片复算

每张资产卡片给出 `原值 / 转固日期 / 折旧年限 / 残值率`，审计师可以独立重算：

```
年折旧额 = 原值 × (1 − 残值率) ÷ 折旧年限
当月增加当月不提，次月起计提；累计折旧封顶到"应计折旧总额"
```
